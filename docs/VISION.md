# TULPAR Vision

## What is TULPAR?

TULPAR is an autonomous systems platform.

It provides a common infrastructure for autonomous aerial, ground and marine vehicles.

Instead of developing software separately for every vehicle, TULPAR offers reusable components such as communication, mission execution, artificial intelligence integration, navigation and telemetry.

The first supported platform will be an autonomous drone.

---

## Long-Term Goal

Build an open, modular and scalable ecosystem for autonomous systems.

---

## Core Principles

- Modular Architecture
- Hardware Independence
- Simulation First

- Open Standards
- Extensible by Design
