# TULPAR Protocol (TP)

## Purpose

TULPAR Protocol is the native communication protocol used between autonomous vehicles, ground stations and platform services.

The protocol is designed for:

- Low latency
- High reliability
- Modular packet structure
- Secure communication
- Cross-platform compatibility

---

## Planned Packet Types

- HEARTBEAT
- PING
- PONG
- AUTH
- TELEMETRY
- COMMAND
- EVENT
- LOG
